# GitHub User Finder

A modular web application that searches GitHub users, displays profile details, and lists their 5 most recently updated repositories using the GitHub REST API and modern ES Modules.

---

## 🚀 How to Run the Project

Because this project uses modern ES Modules (`import`/`export`), it must run on a local HTTP server:

### 1. Start the Local Server
In PowerShell, navigate to the project directory and run:

```bash
npx.cmd serve .
